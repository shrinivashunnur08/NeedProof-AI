# Evidence map for jury-facing claims

| Claim | Current proof | Safe wording | What would upgrade it |
| --- | --- | --- | --- |
| Works on fresh user input | 17C local request/response with fictional merchant updates; local 17G health/probe | "Local end-to-end React/FastAPI demo with fresh fictional decisions" | Hosted authenticated browser-to-API trace on deployed revision |
| Knows when to refuse purchase | 17G local gate, 18A fictional cases, 18B fail-closed checks | "On the authored offline cases, purchase stays unauthorized" | Adversarial production authorization and independent security testing |
| Evidence provenance and contradiction handling | 17D source tags/hash binding, fictional docs/conflicts | "Tracks claimed evidence and finds inconsistent excerpts" | Verified source identity and independent external reference checks |
| Next best verification | 17E queue/hypothetical EVSI | "Computes a verification priority under illustrative assumptions" | Calibrated utility/reply distributions and observed user outcomes |
| Better than simple heuristics | 17F and 18B controlled fictional comparisons | "Outperforms price-only and stock/budget, ties strong rules" | Blinded, representative independent datasets, statistical uncertainty |
| Better than strong structured rules | **No supporting measurement** | "Not demonstrated; tied on authored state-classification tests" | Unseen unstructured/task-completion experiments with defensible ablation |
| Real Gemini-backed live reasoning | Integration code exists; no authorized live model probe | "Gemini is included in the architecture but live behavior is unverified" | Approved controlled invocation with actual output/latency/billing |
| Actual merchant stock or customers saved money | **No observations** | "These are future pilots and hypotheses" | Consented participating merchants, stock checks, outcomes |
| Production-ready/secure hosted flow | Local gates only; Firebase/Cloud Run IAM/App Check not verified end to end | "Local proof-of-concept, pending hosted authorization testing" | Real locked-down browser, Auth/App Check, Cloud Run, security review |
| Economically viable | Hypothetical $3.70/1000 arithmetic at editable assumptions | "Illustrative cost model, not cloud bill or ROI" | Real provider bills, usage volume and measured value |

**Rule:** Never change a source status flag just to make the final status green. Capture proof with timestamp and verification method, review separately, then revise the claim and its citations. Generated `qa_reports/` are disposable audit outputs and should not be committed by default.
